# Glosario

Este archivo define el lenguaje ubicuo del dominio. Todo concepto de negocio debe tener un nombre unico, una definicion clara y un contexto donde ese nombre tiene sentido.

## Reglas

* Escribe siempre los conceptos entre backticks: `Concepto`.
* Usa el mismo nombre para el mismo concepto en todos los documentos.
* Si una palabra tiene significados distintos, separa las definiciones por contexto.
* Evita sinonimos no controlados.
* No incluyas detalles tecnicos de implementacion.

```md
## `[Concepto]`

**Contexto:** `[Contexto]`

**Definicion:** [Descripcion corta y funcional.]
```
